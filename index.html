처음 오셨나요?

구글 Gemini API 키를 등록하면
사내 규정 챗봇이 열립니다

키는 이 브라우저 안에만 저장됩니다. 회사 서버나 외부로 보내지 않습니다.

✔ 키가 저장되어 있습니다

1 무료 키 받는 법 (5단계)

  1. 아래 파란 주소를 눌러 구글 AI 스튜디오 사이트를 엽니다. 구글 계정(지메일) 로그인이 필요합니다. 회사 계정도 됩니다. https://aistudio.google.com/apikey ↗
  2. 화면 오른쪽 위의 [API 키 만들기] 버튼을 누릅니다. 영어로 보이면 [Create API key] 입니다.
  3. 프로젝트를 고르라는 창이 나오면 목록에서 아무거나 하나를 고르거나, [새 프로젝트에서 만들기]를 누릅니다. 처음이라면 목록이 비어 있을 수 있습니다. 그때는 새로 만들기를 누르면 됩니다.
  4. 몇 초 뒤 AIza로 시작하는 긴 글자가 만들어집니다. 옆의 [복사] 아이콘을 누릅니다. 이 글자가 바로 키입니다. 다른 사람에게 알려주지 마세요.
  5. 아래 입력란에 붙여넣고 [키 저장하고 시작하기]를 누릅니다. 붙여넣기는 키보드 Ctrl+V (맥은 ⌘+V) 입니다.

2 받은 키를 여기에 붙여넣기

키는 화면에 ●●● 로 가려져 표시됩니다. 오른쪽 눈 모양을 누르면 확인할 수 있습니다.

· 입력한 키는 이 컴퓨터의 브라우저 저장 공간에만 남습니다. 다음 방문 때 다시 묻지 않습니다.
· 공용 컴퓨터에서 사용했다면 자리를 뜨기 전에 [키 삭제]를 눌러 주세요.
· 키를 잊어버려도 괜찮습니다. 위 사이트에서 새로 만들면 됩니다.
